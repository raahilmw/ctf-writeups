## 📚 Methodology

Every write-up follows a structured approach:

1. **Reconnaissance** — Identify open ports, services, and versions
2. **Enumeration** — Gather detailed information about discovered services
3. **Vulnerability Analysis** — Research known CVEs and potential attack vectors
4. **Exploitation** — Execute the attack to gain access
5. **Post-Exploitation** — Enumerate the system and capture the flag
6. **Mitigation** — Document recommendations to fix the vulnerability
